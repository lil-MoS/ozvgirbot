# ربات عضو گیر گروه/کانال تلگرام (OzvGirBot)

یک ربات تلگرامی که به کاربران امکان می‌دهد با عضویت در کانال‌ها و گروه‌ها سکه جمع‌آوری کنند، کانال یا گروه خود را برای جذب عضو ثبت کنند، دوستان خود را دعوت کنند و سکه خریداری کنند. این ربات با پایتون و کتابخانه `python-telegram-bot` ساخته شده و از SQLite برای ذخیره داده‌ها استفاده می‌کند.

## ویژگی‌ها
- 💰 جمع‌آوری سکه با عضویت در کانال‌ها/گروه‌های تبلیغ‌شده
- 📢 ثبت کانال/گروه برای جذب عضو با استفاده از سکه
- 📣 زیرمجموعه‌گیری: کسب ۵ سکه به ازای هر نفر دعوت‌شده
- 🛒 خرید سکه از طریق درگاه پرداخت (زرین‌پال)
- ⚙️ مدیریت ادمین: مشاهده آمار، ارسال پیام همگانی، افزودن سکه، و دریافت فایل پایگاه داده

## نصب و راه‌اندازی

### پیش‌نیازها
- پایتون نسخه ۳.۶ یا بالاتر
- توکن ربات تلگرامی از [@BotFather](https://t.me/BotFather)
- آیدی عددی ادمین (شناسه عددی تلگرام)
- TOKEN = "_"
- ADMIN_ID = "_"
- آیدی چنل خودتون رو نیز جایگزین کنید و بات رو در چنل مدیر کنید و تمام دسترسی هارو بهش بدید 🤖
