راه‌اندازی:
توکن ربات و آیدی ادمین را در متغیرهای TOKEN و ADMIN_ID وارد کنید.
کد را اجرا کنید: python ozv.py
ربات پایگاه داده را به‌صورت خودکار ایجاد می‌کند.
دستورات کاربر:
/start: نمایش منوی اصلی.
قابلیت‌های منو:
جمع‌آوری سکه (عضویت در کانال/گروه و دریافت 1 سکه).
ثبت کانال/گروه (نیاز به ادمین بودن ربات و صرف سکه).
مشاهده تعداد سکه‌ها.
زیرمجموعه‌گیری (دریافت 5 سکه به ازای هر دعوت).
خرید سکه (از طریق لینک زرین‌پال).
تنظیمات (بررسی ادمین بودن ربات).
راهنما.
دستورات ادمین:
/stats: نمایش آمار (تعداد کاربران، کانال‌ها، گروه‌ها).
/broadcast_users: ارسال پیام به همه کاربران.
/broadcast_chats: ارسال پیام به کانال‌ها/گروه‌ها.
/coin: افزودن سکه به کاربر خاص.
/db: دریافت فایل پایگاه داده.
/help: نمایش راهنمای ادمین.
